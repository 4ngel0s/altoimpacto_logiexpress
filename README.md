# LOGIEXPRESS 1.1 — Pacote de documentação e 20 exercícios

Este pacote mantém a aplicação Flask com CRUD de Clientes e adiciona:

- Documentação Técnica
- Documentação Auxiliar
- Guia Git e Integração
- Kanban do Produto
- 20 Exercícios de Desenvolvimento
- Instruções 29/09 como etapa de preparação, sem separar o desenvolvimento por data

## Rotas adicionadas

- `/documentacao-tecnica`
- `/documentacao-auxiliar`
- `/guia-git-integracao`
- `/desafios`
- `/kanban`
- `/instrucoes`

## Atenção

Copie o `app.py` e os templates para o seu Codespace atual, preservando os demais arquivos e recursos já existentes.
