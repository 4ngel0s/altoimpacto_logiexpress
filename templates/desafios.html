20 Exercícios de Desenvolvimento

Backlog de evolução do LOGIEXPRESS. Os grupos podem iniciar as atividades assim que o ambiente estiver preparado.

Regra de integração: não desenvolver diretamente em main. Cada grupo trabalha em sua branch e entrega por Pull Request para develop.

Como escolher um exercício

O exercício é uma demanda de produto. Antes de programar, o grupo deve entender o requisito, localizar no código os pontos que serão afetados, registrar a tarefa no Kanban e definir sua branch.

Os exercícios podem ser distribuídos pelo professor ou escolhidos conforme a organização do Kanban. O objetivo é terminar com as funcionalidades integradas em uma única aplicação.

Fluxo obrigatório do desenvolvimento

Kanban → análise → branch → desenvolvimento → teste → commit → push → Pull Request → revisão → merge em develop → teste integrado → main

Branch sugerida: feature/grupo-01-manutencao

Objetivo: Criar um módulo para registrar manutenções preventivas e corretivas dos veículos.

Requisitos

Criar cadastro/listagem/visualização com veículo, tipo, data, quilometragem, descrição, custo e status. Permitir identificar manutenções abertas.

Critérios de aceite

Não salvar sem veículo, tipo e data; custo não pode ser negativo; listar as manutenções por data.

O grupo deverá entregar
  1. Código integrado ao LOGIEXPRESS.
  2. Interface funcional no navegador.
  3. Validações básicas e regra de negócio definida.
  4. Teste manual documentado.
  5. Commits pequenos e descritivos.
  6. Push da branch.
  7. Pull Request para develop.
