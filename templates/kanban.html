Regra de sincronização

  1. O cartão muda para Em desenvolvimento quando a branch é criada.
  2. Vai para Code Review quando o Pull Request é aberto.
  3. Vai para Teste integrado após o merge em develop.
  4. Vai para Done somente após validação.
