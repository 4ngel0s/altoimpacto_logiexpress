Instruções — 29/09

Preparação do ambiente, leitura do sistema e início do desenvolvimento colaborativo do LOGIEXPRESS.

Objetivo: acessar o ambiente, entender a aplicação existente e iniciar o trabalho de desenvolvimento. Os exercícios podem começar a ser executados imediatamente após a preparação.

1. Acesso ao GitHub

  1. Acesse o GitHub e confirme sua conta.
  2. Entre no repositório da turma/projeto.
  3. Verifique se consegue visualizar os arquivos do LOGIEXPRESS.
  4. Ative autenticação em dois fatores ou passkey quando disponível.

2. GitHub Codespaces

  1. Abra o repositório.
  2. Crie ou abra o Codespace.
  3. Confirme que o projeto aparece no Explorer.
  4. Use o Terminal integrado para executar os comandos.

3. Conheça o projeto

app.py
templates/
static/
tests/
docs/
requirements.txt
README.md
render.yaml

Antes de alterar qualquer código, abra os arquivos e identifique onde ficam o backend, as páginas HTML, os estilos, os testes e a configuração de dependências.

4. Execute a aplicação

python3 app.py

Abra a porta disponibilizada pelo Codespace e confirme que o Dashboard, Cadastros, Relatórios e documentação estão funcionando.

5. Antes de desenvolver

  • Leia a Documentação Técnica.
  • Leia a Documentação Auxiliar se algum conceito for novo.
  • Leia o Guia Git e Integração.
  • Escolha ou receba um dos 20 exercícios.
  • Entre no Kanban e registre a atividade como Backlog/Ready antes de iniciar.

Ambiente preparado

Quando o sistema estiver abrindo no navegador e você conseguir localizar o código, a documentação, o Git e o Kanban, você está pronto para iniciar um exercício.
