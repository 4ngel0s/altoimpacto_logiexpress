{% if id == 'branch' %}
Como usaremos
main       → versão estável
   ↓
develop    → integração das equipes
   ↓
feature/grupo-01-manutencao
feature/grupo-02-combustivel
feature/grupo-03-ocorrencias
...

Cada grupo trabalha na sua branch. Isso reduz a possibilidade de uma equipe sobrescrever o trabalho da outra.

{% elif id == 'commit' %}
Exemplo
git add .
git commit -m "feat: adiciona controle de manutenção"

O commit deve representar uma alteração coerente. Evite mensagens vagas como alterações ou teste.
